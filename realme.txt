Project: Quantum-Enhanced Financial Risk & Scenario Analysis
Event: Amrita QuantumLeap Bootcamp 2026 Hackathon

Description:
A complete, professional Streamlit application that contrasts classical financial risk modeling (Monte Carlo simulations) with a Quantum Circuit Born Machine (QCBM) using Qiskit.

Files Included:
- app.py: The main Streamlit file handling the UI, ticker input, and display.
- quantum_logic.py: Backend for the 4-qubit QCBM circuit using Qiskit. Maps measurement probabilities to return states in [μ−3σ, μ+3σ].
- finance_logic.py: Backend for classical analysis, fetching 2 years of daily returns via yfinance, calculating Value at Risk (VaR), and running 4-year Monte Carlo simulations.
- README.md: Documentation detailing setup instructions and project features.

Setup:
pip install streamlit yfinance pandas numpy matplotlib qiskit qiskit_aer scipy pylatexenc

Run:
streamlit run app.py
